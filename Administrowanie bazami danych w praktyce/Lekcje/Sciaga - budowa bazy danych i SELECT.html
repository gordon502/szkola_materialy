1 Mapa: od przeglądarki do pojedynczej komórki

Czytaj od góry do dołu — każde pudełko siedzi w środku poprzedniego.

👤 UŻYTKOWNIK (Ty) + przeglądarka

Klikam i piszę zapytania. Nie dotykam plików bazy bezpośrednio — zawsze przez program.

↓
🖥️ phpMyAdmin — http://localhost/phpmyadmin

Strona WWW, czyli narzędzie do klikania. Sama nic nie pamięta — tłumaczy moje kliknięcia i zapytania SQL na polecenia dla serwera i pokazuje odpowiedź w tabelce. (W XAMPP muszą działać Apache = strona i MySQL = serwer bazy.)

⚙️ SZBD — System Zarządzania Bazą Danych (MySQL / MariaDB)

Właściwy program-serwer. To on przechowuje dane, wykonuje SELECT, pilnuje typów danych, kluczy i uprawnień użytkowników. Na jednym SZBD może stać wiele baz.

2 SELECT — jak wyciągnąć dane

Wszystkie przykłady na bazie szkola z góry strony. Zapytanie kończymy średnikiem ;

SELECT Które kolumny chcę zobaczyć?* = wszystkie kolumny
FROM Z której tabeli je wziąć?np. uczniowie
WHEREnieobowiązkowe Które wiersze mnie interesują?filtr — reszta wierszy w ogóle się nie pokaże
ORDER BYnieobowiązkowe Jak posortować wynik?ASC rosnąco (domyślnie) · DESC malejąco
LIMITnieobowiązkowe Ile wierszy pokazać?np. LIMIT 10 — pierwsze dziesięć

Kolejność tych linijek jest sztywna — WHERE nigdy przed FROM, LIMIT zawsze na końcu.

A. Wybieranie kolumn

* — wszystko

Cała tabela: wszystkie kolumny i wszystkie wiersze.

SELECT * FROM uczniowie;
Efekt: lista wszystkich uczniów ze wszystkimi danymi.

Wybrane kolumny

Mniej śmieci na ekranie — biorę tylko to, co potrzebne.

SELECT imie, nazwisko, srednia
FROM uczniowie;
Efekt: 3 kolumny, wciąż wszyscy uczniowie.

AS — własny nagłówek

Zmieniam podpis kolumny w wyniku (dane w tabeli zostają bez zmian).

SELECT nazwisko AS Uczen,
       srednia  AS "Średnia ocen"
FROM uczniowie;
Efekt: nagłówki „Uczen” i „Średnia ocen”.

DISTINCT — bez powtórek

Pokaż każdą wartość tylko raz.

SELECT DISTINCT profil FROM klasy;
Efekt: lista profili, np. informatyczny, logistyczny, mechaniczny.

Obliczenia w SELECT

Kolumna, której nie ma w tabeli — liczona na bieżąco.

SELECT nazwa,
       godziny_tyg * 32 AS GodzinyWRoku
FROM przedmioty;
Efekt: wolno używać + - * / na kolumnach liczbowych.

Funkcje na wartościach

Przerabiam to, co wychodzi w wyniku.

SELECT UPPER(nazwisko)              AS Nazwisko,
       LENGTH(nazwisko)             AS DlugoscZnakow,
       CONCAT(imie,' ',nazwisko)    AS PelneImie,
       ROUND(srednia, 1)            AS SredniaZaokr
FROM uczniowie;
Efekt: KOWALSKA · 8 · „Anna Kowalska” · 4.4

B. WHERE — filtrowanie wierszy

Porównania = <> > < >= <=

Najprostszy warunek. Tekst i daty w apostrofach, liczby bez.

SELECT * FROM uczniowie
WHERE srednia > 4.0;
SELECT * FROM klasy
WHERE nazwa = '2TI';
SELECT * FROM oceny
WHERE ocena <> 1;   -- różne od 1

AND — oba warunki naraz

Zawężam wynik: musi się zgadzać wszystko.

SELECT imie, nazwisko, srednia
FROM uczniowie
WHERE id_klasy = 3
  AND srednia >= 4.0;
Efekt: tylko dobrzy uczniowie z klasy nr 3.

OR / NOT

OR — wystarczy jeden warunek. NOT — odwrotność.

SELECT * FROM przedmioty
WHERE nazwa = 'Matematyka'
   OR nazwa = 'Fizyka';
SELECT * FROM klasy
WHERE NOT profil = 'informatyczny';
Uwaga: mieszając AND z OR używaj nawiasów — WHERE a=1 AND (b=2 OR b=3).

BETWEEN — przedział

Od… do…, razem z krańcami. Działa też na datach.

SELECT nazwisko, srednia FROM uczniowie
WHERE srednia BETWEEN 3.0 AND 4.0;
SELECT * FROM oceny
WHERE data_wystawienia
      BETWEEN '2026-09-01' AND '2026-09-30';
To samo co: srednia >= 3.0 AND srednia <= 4.0

IN — lista wartości

Skrót zamiast wielu OR.

SELECT * FROM uczniowie
WHERE id_klasy IN (1, 3, 5);
SELECT * FROM przedmioty
WHERE nazwa IN ('Matematyka','Fizyka','Chemia');
Odwrotnie: NOT IN (1,3,5) — wszyscy poza tymi klasami.

LIKE — wzorzec tekstu

% = dowolny ciąg znaków (także pusty) · _ = dokładnie 1 znak

WHERE nazwisko LIKE 'K%'    -- zaczyna się na K
WHERE nazwisko LIKE '%ski'  -- kończy na "ski"
WHERE nazwisko LIKE '%ow%'  -- zawiera "ow"
WHERE imie     LIKE '_a%'   -- 2. litera to a
WHERE email    LIKE '%@zsp.pl'
Efekt: Kowalska · Zieliński · Kowalska/Nowak · Bartosz/Damian

IS NULL — puste pola

NULL to brak wartości — nie równa się niczemu, nawet sobie.

SELECT imie, nazwisko FROM uczniowie
WHERE email IS NULL;
SELECT * FROM uczniowie
WHERE email IS NOT NULL;
Nigdy: WHERE email = NULL — zwróci 0 wierszy!

Warunek na wyniku obliczenia

W WHERE powtarzam całe wyrażenie — alias z SELECT tu nie działa.

SELECT nazwa, godziny_tyg * 32 AS GodzinyWRoku
FROM przedmioty
WHERE godziny_tyg * 32 > 100;
Dlaczego: WHERE wykonuje się przed SELECT.

C. Porządkowanie wyniku

ORDER BY — sortowanie

ASC = rosnąco (domyślnie), DESC = malejąco.

SELECT nazwisko, srednia FROM uczniowie
ORDER BY srednia DESC;
-- najpierw klasa, w klasie alfabetycznie
SELECT * FROM uczniowie
ORDER BY id_klasy ASC, nazwisko ASC;

LIMIT / OFFSET

Ile wierszy pokazać i od którego zacząć.

-- 5 najlepszych średnich
SELECT nazwisko, srednia FROM uczniowie
ORDER BY srednia DESC
LIMIT 5;
-- wiersze 11–20 (pomiń 10)
SELECT nazwisko FROM uczniowie
ORDER BY nazwisko
LIMIT 10 OFFSET 10;

Wszystko razem

Kolejność klauzul jest sztywna — nie wolno zamieniać miejscami.

SELECT CONCAT(imie,' ',nazwisko) AS Uczen,
       srednia AS Srednia
FROM uczniowie
WHERE id_klasy IN (1,3)
  AND srednia >= 3.5
  AND email IS NOT NULL
ORDER BY srednia DESC
LIMIT 10;
Czytaj jak zdanie: pokaż… z tabeli… tylko te… posortowane… pierwsze 10.

⚠️ Najczęstsze błędy

  • WHERE email = NULL → ma być IS NULL.
  • Tekst bez apostrofów: WHERE nazwa = 2TI → ma być '2TI'.
  • Ułamki z przecinkiem: srednia > 4,5 → w SQL zawsze kropka: 4.5.
  • Zła kolejność: ORDER BY zawsze po WHERE, LIMIT na samym końcu.
  • Alias w WHERE: WHERE GodzinyWRoku > 100 nie zadziała — powtórz wzór.
  • Brak średnika ; albo literówka w nazwie kolumny — MySQL pokaże czerwony błąd, przeczytaj go!
Tu się na razie zatrzymujemy.
Zliczanie i podsumowywanie danych (COUNT, SUM, AVG) — na kolejnych lekcjach.

3 Klatka po klatce: co serwer robi z moim zapytaniem

Jedna tabela, 10 wierszy i jedno zapytanie — z AND, OR, ORDER BY i LIMIT naraz. Klikaj Dalej → i patrz, co znika, co się przestawia i dlaczego kolejność klauzul ma znaczenie. (Możesz też używać strzałek ← → na klawiaturze.)

SELECT imie, nazwisko, srednia AS "Średnia ocen" FROM uczniowie WHERE (id_klasy = 1 OR id_klasy = 3) AND srednia >= 3.5 ORDER BY srednia DESC LIMIT 3;
